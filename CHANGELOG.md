# История изменений

Все заметные изменения проекта фиксируются в этом файле.

## 0.1.0 - 2026-06-26

- Добавлен кроссплатформенный запуск через `start.py`, `run.sh` и `run.bat`.
- `start.py` теперь автоматически создаёт `.venv` и устанавливает зависимости при первом запуске.
- Добавлена лицензия MIT и CI-проверка тестов в GitHub Actions.
- Добавлен логотип инструмента в README и публичные assets проекта.
- README сверён с Chroma Engineering Constitution: добавлены статус, инженерная позиция, архитектура, scope релиза и известные ограничения.
- Добавлен `pyproject.toml` с метаданными проекта, зависимостями, pytest-настройками и командой `excel-pair-processor`.
- `requirements.txt` оставлен только для runtime-зависимостей; тестовые зависимости вынесены в `.[test]`.
- Исправлена поддержка Windows-запуска: `run.bat` пробует `py`, затем `python`.
- Выходные `.xlsx`/`.csv` и dry-run отчёты больше не перезаписывают существующие файлы; для повторных запусков добавляется числовой суффикс.
- Исправлен выбор колонок в GUI: удалённые из выбранных колонки возвращаются в доступные.
- Добавлена валидация полей `Допуск Time*` и `Потоков`.
- Предварительная проверка теперь проверяет все пары файлов, а не только первую.
- Улучшена обработка чисел с запятой в Excel-данных.
- Удалены локальные артефакты из публичного релиза.
